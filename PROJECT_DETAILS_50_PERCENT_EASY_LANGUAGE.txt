# DeepFake Detection Project Report (50% Completion Snapshot)

## 1. Title
DeepFake Detection Using Multi-Signal Analysis (Mid-Development: 50% Work Completed)

## 2. Abstract (Easy Language)
This project aims to detect whether a video is real or manipulated (deepfake) by combining multiple signals instead of depending on one model.

In this 50% completion snapshot, core pipeline foundations are implemented:
- video and audio preprocessing
- face and landmark extraction
- behavioral analysis (blink and lip-sync)
- initial visual artifact analysis with CNN integration
- React + FastAPI application workflow for practical usage

Advanced calibration, production-grade NLP, and final optimization are intentionally kept for the remaining 50% work.

## 3. Problem Statement
Deepfake videos are becoming realistic, and single-model detection is not reliable in many real-world cases. A practical detector should:
- use different evidence types
- provide explainable output
- support web-based usage for users and reviewers

This project addresses these needs through a modular, explainable architecture.

## 7. Exact Implementation Process (Up to 50%)

### 7.1 Input Handling
1. User uploads a video from React UI.
2. Backend stores the file in uploads directory.
3. A job id is created and status is tracked in memory.

### Dataset and Training Pipeline Status
The project already includes a full data workflow:

- Ingest from FaceForensics++
- Ingest custom real/fake folders
- Create video manifests
- Build train/val/test splits
- Preprocess splits into frames/audio/faces
- Build face-level manifests
- Train and evaluate a lightweight CNN model

This means end-to-end data preparation and model training flow is available.

### 7.2 Preprocessing
1. Read video metadata (fps, frame count, dimensions, duration).
2. Extract audio into WAV format (16 kHz target).
3. Extract keyframes at fixed interval (0.2s in current pipeline).
4. Save timestamp mapping for frame-to-time alignment.

### 7.3 Face and Landmark Stage
1. Detect face in key frames (MediaPipe first, OpenCV fallback).
2. Extract facial landmarks for valid frames.
3. Skip frames where face/landmark extraction is unavailable.

### 7.4 Behavioral Detection
Blink detection:
- compute Eye Aspect Ratio (EAR) from eye landmarks
- detect blink windows when EAR stays below threshold over consecutive frames
- derive blink count and blink irregularity

Lip-sync detection:
- compute mouth openness timeline from lip landmarks
- compute audio envelope from extracted audio
- align both timelines using timestamps
- compute correlation, time offset, and error

### 7.5 Visual Detection (Initial)
1. Crop detected face region.
2. Compute handcrafted artifact features:
- sharpness
- texture spread
- brightness variance
- lighting asymmetry
3. Run lightweight CNN on face crop (if weights available).
4. Obtain fake probability from CNN class-1 softmax output.

### 7.6 Initial Decision Fusion
Current fusion combines module scores with weighted logic:
- blink
- lip-sync
- visual
- watermark (initial)
- nlp (initial)

Output includes:
- confidence score
- risk level
- module scores
- explainable reasons

This is a working baseline, but final calibration is reserved for the remaining 50% work.
